---
title: Layout a Page
summary: Get content on a page to layout consistently.
---

On Content pages, we usually group the page into sections to create more visually interesting layouts. Each section of the page should be wrapped in a group block to get the spacing correct. Think of each outer group as the section.

## Background Colors

Add a highlight to your page with groups with a background color.

|                                                              |                                                              |
| ------------------------------------------------------------ | ------------------------------------------------------------ |
| ![image-20261002094300990](images/image-20261002094300990.png) | Choose Section - Dark Background or Section - Light Background to get the preconfigured group. |
| ![image-20261002094627932](images/image-20261002094627932.png) | Light background has a light gray background with borders.   |
| ![image-20261002094711859](images/image-20261002094711859.png) | Dark background has a blue background, this could be switched to Green. <br /><br />When putting a dark background on a group, the text inside should automatically display in the contrasting color. |
| ![image-20261002095034585](images/image-20261002095034585.png) | You can change the background color in the block style settings tab |
| ![image-20261002095120541](images/image-20261002095120541.png) | If you want to convert an existing group to use a background, be sure to set the width to **Full** |
